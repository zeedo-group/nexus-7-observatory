# Project Context & Scope

## Project Summary
Building an ultra-smart, minimalistic, futuristic alien website for "diw" (Deep Intelligence World).
The website is a Vite + React + TypeScript web app featuring:
- Futuristic dark cybernetic alien aesthetic.
- Multiple specialized pages: Home, Lore Codex, Agent Network Portal, Alien Species, Alien Worlds, Artifacts, Transmissions.
- Dozens of generated alien assets (landscapes, species, tech, glyphs, agent portraits).
- Interactive 3D WebGL / Three.js alien artifact / planet visualization.
- Functional IndexedDB backend database for lore storage, search, custom lore creation, and persistence.
- Interactive multi-agent system simulation (Coder Agent, Image Generator Agent, Planner Agent).

## Key Files & Directories
- `package.json` — Vite, React 19, Lucide React, TypeScript
- `src/` — React app source code
- `public/assets/` — Image assets repository
- `.agents/` — Agent coordination & metadata workspace
